# 语音与人物动画协作约定（初始草案）

语音库负责生成或加载音频、控制播放，并提供播放状态；动画库负责人物表现。

| 事件 | 动画表现 |
| --- | --- |
| listening | 倾听，嘴巴闭合 |
| thinking | 思考 |
| speech-start | 切换到说话 |
| speech-level，level 取值 0–1 | 依据实际音频能量驱动嘴型 |
| speech-end / speech-stop / speech-error | 闭嘴，平滑回到待机 |

事件携带同一条语音的 `utteranceId`，停止或切换语音后忽略过期事件。没有实际播放的音频时不触发说话动作。以上为待实现的接口约定，不代表已有功能。
