# 阿德语音库 · ade-voice

得体说「阿德」IP 的声音配置、语音素材目录及接入说明。

当前为仓库初始化版本：尚未迁入运行代码、模型或音频，不能直接启动语音服务。

## 目录

- `voices/`：声线、语气和试听素材索引。
- `samples/`：后续存放经确认的短试听。
- `src/`：后续存放语音合成与播放适配代码。
- `docs/integration.md`：与人物动画库的协作约定。

## 素材规则

每条语音记录声线编号、语气、文本、音频路径、来源、授权及版本。原始录音、模型权重和生成缓存不直接纳入本仓库。试听候选与正式选定声线分别标记，避免误用。

## 配套仓库

人物动画：[ade-character-animation](https://github.com/tenglongliu520-wq/ade-character-animation)。

## 使用与授权

目前未添加开源许可证；代码、角色形象、声音素材及第三方模型的授权分别确认。仓库初始按私有使用准备。
