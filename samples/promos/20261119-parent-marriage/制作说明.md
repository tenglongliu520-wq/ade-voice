# 得体说｜父母催婚｜15秒竖屏

720×1280、9:16、30fps、15秒、H.264/AAC MP4。

依据用户附件《03_接到父母催婚电话.docx》及本轮补充反问台词。按用户明确要求将附件25秒的方案压缩为15秒；根据所提供的男女人物照片，父母来电改为爸爸角色。

0–2.7秒：爸爸：“对象找了吗？周末去见见吧。”
2.7–8秒：女儿：“如果我随意找一个，将来不幸福会离婚，也是您希望看到的吗？”
8–9.7秒：打开得体说，真实截图，旁白“先和得体说聊聊”。
9.7–12.5秒：换种表达：“爸，我懂您担心，但幸福不能将就。”
12.5–15秒：得体说，陪你把话说好。阿德及产品介绍收尾。

采用人物静态图片动态剪辑、通用中文合成语音、字幕及自制提示音；不是写实人物口型生成，不克隆照片人物或阿德声线。回应为情景示例，不冒充产品实际生成结果。用户照片与成片保留本地，公开仓库只同步通用配音、渲染源码和制作说明。


语音：ade-voice/samples/promos/20261119-parent-marriage/voice-0.mp3 至 voice-4.mp3；通用 Microsoft Edge TTS，zh-CN-YunjianNeural（爸爸）、zh-CN-XiaoxiaoNeural（女儿及旁白）。每句经ffmpeg适配镜头时长，不含个人录音。
渲染器：ade-character-animation/examples/promos/20261119-parent-marriage/make_video.py。
自备获授权的 assets/client.jpg（爸爸）、assets/worker.jpg（女儿）、assets/product.jpg（真实产品截图），均与脚本相邻。用户本次照片及完整视频不包含在公开仓库中。
安装：python -m pip install --target vendor -r requirements.txt
运行：python make_video.py
如复用已生成音频，将五段MP3复制到渲染脚本同目录，运行 python make_video.py --render-only。
