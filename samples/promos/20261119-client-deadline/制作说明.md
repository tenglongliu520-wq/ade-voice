# 客户临时催方案｜得体说15秒宣传片

2026-11-19。9:16、720×1280、30fps、15秒。

0–2.8秒：客户：方案今天必须给，来得及吧？
2.8–4.6秒：主角内心：你当我会分身啊？（明确标注脑内弹幕，尚未发送）
4.6–6.5秒：先问问得体说，切入用户提供的真实产品截图。
6.5–11.5秒：我先确认关键部分，今天给您准确时间。
11.5–15秒：得体说，陪你把话说好。

本片使用图片推近、切镜、字幕及通用合成语音，不是人物口型生成，也不克隆照片人物或阿德的声线。回应为剧情示例，不冒充网站实际生成结果。
配音：Microsoft Edge TTS，zh-CN-YunjianNeural（客户）、zh-CN-XiaoxiaoNeural（内心、回应和品牌旁白）。每句生成后以ffmpeg适配镜头时长；不含个人录音。音效为脚本合成。

语音素材：ade-voice/samples/promos/20261119-client-deadline/voice-0.mp3 至 voice-4.mp3。
渲染源文件：ade-character-animation/examples/promos/20261119-client-deadline/make_video.py。
将获授权的人物及产品截图分别放在渲染脚本同目录 assets/client.jpg、assets/worker.jpg、assets/product.jpg。用户图片与最终含人物照片的视频只在本地交付，不包含于公开仓库。

安装依赖：python -m pip install --target vendor -r requirements.txt
运行：python make_video.py
复用已生成的语音时，将五段MP3复制到脚本同目录，运行 python make_video.py --render-only。

项目本地成品位于 outputs/detishuo-ad-20261119/，分镜核验图、封面及编码核验日志与成品同目录。
